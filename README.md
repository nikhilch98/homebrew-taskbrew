# Homebrew Tap for TaskBrew

Multi-agent AI team orchestrator for Claude Code, Gemini CLI, and custom agents.

## Installation

```bash
brew tap nikhilch98/taskbrew
brew install taskbrew
```

## Usage

```bash
taskbrew init --name my-project
taskbrew doctor
taskbrew start
```

For more information, see the [TaskBrew repository](https://github.com/nikhilch98/taskbrew).
